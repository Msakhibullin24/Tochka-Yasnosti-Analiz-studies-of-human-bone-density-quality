# Продолжение: устойчивость анатомии к полярности и яркости

Добавлен `competition/refine_anatomy_photometry.py`: дообучение головы масок на фиксированных разбиениях предыдущих этапов. Используются только существующие аннотации AASCE и Hologic. Ранее v2 обучался на инверсии поясничных фрагментов; полный снимок и исходные DXA не имели аналогичной пары в обучении.

Новый этап добавляет 364 преобразования только обучающих родителей: 340 инверсий полного AASCE, 8 инверсий DXA и 16 вариантов гаммы DXA. Оригинальные изображения и маски не меняются. Геометрические координаты, классы и неизвестные области аннотаций сохраняются. Эти преобразования моделируют свойства изображения, а не физику конкретного сканера.

Повторно используются проверенный кэш исходных признаков и 680 поясничных фрагментов v2. Порядок родителей фрагментов сверяется с предыдущим манифестом, SHA-256 исходного кэша — с предыдущим обучением. Новые признаки занимают около 1,04 ГБ. Обучение начинается с головы v2, ResNet остаётся замороженным. Фиксированные 10 эпох и расписание выбираются до просмотра новых отложенных результатов; перебор параметров на holdout не выполняется.

Результаты сохраняются в `data/specialists/runs/anatomy-mask-stage3-20260926/{anatomy_masks.pt,evaluation.json}`. Индивидуальные оценки используют средний Dice известных классов внутри каждого изображения, затем среднее по изображениям. Это исследовательская диагностика на ранее просмотренном holdout, не независимая клиническая валидация. На Hologic остаются только два отложенных пациента.

Команда воспроизведения с новым выходным каталогом:

```bash
competition/.venv/bin/python competition/refine_anatomy_photometry.py \
  --base data/specialists/runs/anatomy-mask-stage1-20260926 \
  --lumbar data/specialists/runs/anatomy-mask-stage2-20260926 \
  --output '/новый/каталог/обучения'
```

CLI `evaluate_anatomy_transfer.py` расширен именами сравниваемых моделей и `--skip-annotated`: источник с готовым отчётом holdout можно сравнить на GE без повторного вычисления тех же аннотированных случаев. Удаление повторов по пикселям сохранено; доступность оси и согласованность прогнозов не считаются точностью нумерации. При таком запуске отчёт явно сообщает, что аннотированная оценка не выполнялась.

## Измеренный результат

| Отложенная аннотация | V2 | Новый кандидат |
|---|---:|---:|
| AASCE, полное поле, 85 изображений | 0,378 | 0,399 |
| AASCE, инверсия полного поля | 0,106 | 0,315 |
| AASCE, поясничный фрагмент, 85 изображений | 0,503 | 0,527 |
| AASCE, инверсия поясничного фрагмента | 0,465 | 0,510 |
| Hologic DXA, 2 изображения | 0,889 | 0,801 |
| Hologic DXA, инверсия | 0,403 | 0,532 |

На 99 уникальных растрах GE, выбранных по прогнозируемой области позвоночника, доступность оси снизилась с 58 до 46 в обычной яркости; при инверсии выросла с 36 до 38. На всех 166 соответствующих DICOM согласованность масок между двумя полярностями снизилась с 0,185 до 0,157. Последняя метрика усреднена по файлам, включая повторы. Она не измеряет клиническую точность на GE; референсных масок GE нет.

**Кандидат не заменяет v2.** Улучшение AASCE и инвертированных DXA сопровождается снижением Dice обычных DXA на существующем holdout. Контрольные суммы кода и артефактов готовых v1/v2 повторно проверены; их инференс-код, веса и решения о качестве не изменены. Для отклонённого кандидата отдельный поставочный профиль и повторный Docker-прогон не создавались.

## Защита от скрытых регрессий

`competition/review_anatomy_candidate.py` сравнивает обычные поля строго по идентичности источника, вида изображения и группы. Разные наборы пациентов, повтор одной записи, некорректный Dice и отсутствующие обычные поля отклоняются. Снижение в одном источнике выводится отдельно, даже если общий результат другой большой выборки вырос. Эта проверка описательная: она не доказывает статистическую не меньшую эффективность и не заменяет клиническую валидацию.

```bash
competition/.venv/bin/python competition/review_anatomy_candidate.py \
  --baseline competition/reports/anatomy_transfer_paired_2026_09_26.json \
  --candidate data/specialists/runs/anatomy-mask-stage3-20260926/evaluation.json \
  --output '/новый/путь/к/сравнению.json'
```

Проверки: 32 целевых теста, затем 17 тестов пути без новой разметки с добавленной проверкой регрессий; все прошли. Проверены все 364 связи производных с обучающими родителями. `git diff --check` пройден.
