# Независимая разметка для проверки анатомии DXA

Подготовленный локальный пакет: `data/tz-delivery-1.11.0/blind-anatomy-review-v4/index.html`.
Откройте его в браузере. Пакет содержит 252 уникальных изображения, редактор
точек, именованных контуров и меток ротации. Для переноса специалисту используйте весь каталог вместе
с `images/`. Это локальные изображения: надписи, уже присутствующие в пикселях,
не удаляются. Проверяйте допустимость передачи данных перед их распространением.

## Порядок работы

1. Укажите специалиста и основание разметки. Независимость отмечается самим
   специалистом; программа не удостоверяет его личность или квалификацию.
2. Выберите проекцию и оцените видимость каждого ориентира. Отсутствие оценки
   отличается от невидимого ориентира. Для видимого ориентира укажите точку.
3. В разделе контуров оцените видимость Th12/L1–L4 либо ROI шейки, бедренной
   кости, большого/малого вертела и седалищной кости. Для видимых областей
   отметьте вершины простого контура по порядку обхода. Контуры костей могут
   быть вогнутыми; ROI шейки должна оставаться выпуклой. Выберите режим
   «Контуры областей» для ввода на снимке; для клавиатуры доступны поля X/Y
   вершины и кнопка добавления. Последнюю вершину можно удалить. Для L1–L4
   размечается тело позвонка соответствующего уровня, а не общий контур позвоночника.
   Для ROI шейки требуется анатомически корректная измерительная область.
4. Для бедра отдельно отметьте два разных конца продольной оси шейки.
   Не выводите её из формы измерительной ROI. Ось не имеет направления;
   перестановка концов эквивалентна. Затем выберите ротацию: нет нарушения, недостаточная, избыточная либо
   не удаётся определить. «Не оценена» не позволяет подтвердить изображение.
5. Подтвердите изображение. Изменение проекции, видимости или точки отменяет
   подтверждение. Подтверждение не означает, что проверены все требования ТЗ.
6. Регулярно скачивайте черновик. Правки не сохраняются автоматически на диск.
   Загрузить можно полный черновик или частичный подтверждённый эталон этого
   же пакета; несовпадающие источники и координаты отклоняются.
7. Скачайте подтверждённый эталон. В него входят только подтверждённые изображения.
   Частичная разметка допустима, но её покрытие указывается в оценке.

На странице отсутствуют предсказанные точки, вероятности и классы качества.
Группа ориентиров (позвоночник/бедро) взята из отчёта маршрутизатора; при ошибке
маршрутизации не подтверждайте изображение и зафиксируйте его для отдельной проверки.
Исходные размеры и ориентация сохранены. Координаты — центры пикселей,
с началом `(0,0)` в левом верхнем углу. Растр нормализуется тем же декодером,
что и инференс; нормализация яркости не меняет геометрию.

## Подготовка нового пакета

```sh
PYTHONPATH=competition competition/.venv/bin/python competition/prepare_anatomy_review.py \
  --results /absolute/results_extended.csv \
  --source /absolute/source-directory \
  --output /absolute/new-review-directory
```

`source` должен соответствовать корню путей `path_to_file`. Для текущего полного
CLI-прогона это распакованная папка `НД_для_обучения`, содержащая `Исследования`.
Упаковщик сверяет UID и размеры, сохраняет SHA-256 файлов и декодированных
пикселей, отклоняет выход за пределы источника и не перезаписывает пакет.
Временный каталог удаляется при ошибке. `manifest.json` фиксирует состав пакета.

## Оценка полученного эталона

```sh
PYTHONPATH=competition competition/.venv/bin/python competition/evaluate_anatomy_review.py \
  --results data/tz-delivery-1.11.0/neck-geometry/local-full/results_extended.csv \
  --source /absolute/source-directory \
  --reference /absolute/anatomy-reference.json \
  --output /absolute/anatomy-validation.json
```

Перед оценкой сверяются SHA-256 отчёта, исходных DICOM и декодированных пикселей.
Неверное происхождение или изменившиеся исходники отклоняются.
Оценка включает ошибки точек в мм при известном масштабе, пропуски видимых
ориентиров, ложное обнаружение невидимых и точность проекции с учётом воздержания.
Параметр `--tolerance-mm` — порог отчёта об ошибках точек, не критерий ТЗ.
Он не превращает локализатор в подтверждённый автоматически.

Вторая версия пакета собирает точки, проекцию, контуры L1–L4/ROI шейки и
отдельные метки ротации. Оценщик сообщает Dice/IoU каждой именованной области,
включая нулевые оценки пропущенных видимых областей. Перестановка L1 и L2
не считается правильной только потому, что обе маски покрывают позвонки.
Для невидимых областей отдельно считаются ложные обнаружения.

Метки ротации подсчитываются отдельно. Точность предсказания её подтипов пока
не вычисляется: текущий runtime не различает их явно. Сходство масок не
подтверждает правильность межпозвоночных границ и клиническую корректность ROI.
До экспертного заполнения и проверки `requirements_complete` остаётся `false`.
Пакеты первой версии сохраняются; их оценщик продолжает принимать как эталон
только точек и проекции.

## Третья версия: независимая ось и полные контуры

Пакет v3 связан с текущим полным прогоном с геометрией шейки. Добавлены
контур видимой части Th12, контуры бедренной кости, обоих вертелов и седалищной
кости, независимая ось шейки. Вогнутые контуры сохраняются без замены выпуклой
оболочкой; самопересечения и повторные вершины отклоняются.

Ошибка оси измеряется в градусах с учётом разных размеров пикселя по X/Y.
Ошибка концов в мм выбирает эквивалентный порядок концов. Пропущенные оси и
предсказания без надёжного масштаба показываются отдельно; средняя ошибка
доступных осей не скрывает покрытие. Угловой порог допуска не выдумывается.

Контур видимой части Th12 не позволяет доказать видимость половины полного
тела, если остальная часть обрезана. Это требование остаётся отдельной задачей.
Пакеты v1/v2 по-прежнему принимаются; не переносите их черновики в пакет v3
без повторной оценки новых полей. Подтверждённых реальных эталонов пока нет.

## Четвёртая версия: оценка полной видимости Th12

Пакет v4 содержит те же 252 исходных DXA: 99 позвоночников и 153 бедра.
Для позвоночника отдельно от видимого контура добавлены четыре угла полной
проекции тела Th12. Углы могут лежать выше или сбоку за границей изображения;
их можно ввести численно. При невозможности обоснованно восстановить полную
границу выберите «Не удаётся оценить», не выдумывая углы. Поле обязательно
для подтверждения позвоночного случая, но состояние «не удаётся оценить»
считается полноценной честной разметкой.

Оценщик сохраняет долю видимой проецируемой площади и долю видимой высоты
отдельно. Доля высоты не объявляется эквивалентом клинического критерия
«половина тела» без согласованного протокола специалистов. Расхождение
видимости полного тела с видимым контуром отклоняется. Точность автоматической
проверки пока не вычисляется: ни один случай ещё не подтверждён специалистом.

Пакет v3 и его черновики остаются в прежнем формате. Черновики v3 нельзя
загрузить в v4: новое поле требует отдельного решения специалиста. При
повторном использовании v3 оценщик сохраняет прежние результаты.

## Раздельная оценка проекции и геометрии шейки

Оценщик подтверждённых случаев теперь показывает матрицу ответов проекции
отдельно для позвоночника и бедра. Явно подсчитывается опасный для допуска
фронтального QC случай: эксперт указал боковую/другую проекцию, а модель
ответила `frontal`. Воздержания сохраняются в знаменателе точности.

Для бедра с видимой экспертной ROI, контуром бедренной кости и независимо
размеченной осью шейки выводятся угол между ROI и осью, участки ROI вне
контура бедренной кости с обеих сторон, пересечение ROI с контурами большого
вертела и седалищной кости. Расчёт ведётся в физических координатах при
достоверном масштабе; отсутствие необходимой разметки, масштаба или
геометрии учитывается отдельно. Это измерения экспертного эталона, а не
проверка исходной ROI: в текущих DICOM её нет. Числовой допуск угла и
минимальная ширина мягкой ткани в ТЗ не указаны; клинический вердикт
остаётся `undetermined`.
