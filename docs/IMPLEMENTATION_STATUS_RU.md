## Что не следует считать завершённым

- Улучшение качества модели бедра. Рабочие веса не заменены: инфраструктурная реорганизация не доказывает прирост F1/AUC.
- Независимая валидация ориентиров и клинический контроль существующих линий ROI. Редактор позволяет подготовить такие данные, но не создаёт экспертный эталон.
- Автоматическое исправление ROI обученной моделью, синхронный просмотр двух визитов, расширенная аналитика. Перемещение точек реализовано в 1.2.0.
- Подготовка обучающего пакета из подтверждённых правок с независимой проверкой принадлежности пациентов/контрольной выборки. Текущий JSON — исходные данные для этой задачи, не автоматическое дообучение.
- Полный сквозной CV с ошибками роутера: сейчас качество оценивается по известной области, роутер отдельно. Это явно записано в отчёте.
- Автопродолжение частично обработанного пакета после аварии. Сейчас выдаётся понятная ошибка с отчётом, повтор требует исходной загрузки.
- Автоматическое долговременное хранение оригинальных DICOM. Сервис сохраняет preview и результаты, исходники удаляются после обработки загрузки.
- Завершённый комплект слайдов и независимый пилот.
