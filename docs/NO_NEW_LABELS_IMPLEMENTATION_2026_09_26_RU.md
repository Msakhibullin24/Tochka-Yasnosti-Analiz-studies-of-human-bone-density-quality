В первом профиле они доступны лишь на 8 из 99 GE-снимков позвоночника; доступность не означает точность локализации. Th12 не присваивается только по порядку от края снимка. Межпозвонковые диски, подвздошные гребни, вертелы и седалищные кости не получили подтверждённой точности от этого обучения. Условия `anatomical_checks_complete` и `requirements_complete` поэтому остаются false.

## Запуск

Из корня репозитория:

```bash
competition/.venv/bin/python competition/run_no_new_labels.py \
  --input '/путь/к/DICOM' \
  --output '/путь/к/результатам' \
  --profile data/specialists/runs/no-new-labels-delivery-20260926/profile.json
```

По умолчанию формируются таблицы, PNG/JSON объяснений и SC/SR. `--no-explanations` отключает дополнительные DICOM серии. Для контейнера укажите реальные абсолютные пути к данным и профилю, заранее создайте каталог результатов:

```bash
docker run --rm --network none --cpus 4 --memory 4g \
  --user "$(id -u):$(id -g)" \
  -v '/путь/к/DICOM:/data/in:ro' \
  -v '/путь/к/no-new-labels-delivery-20260926:/profile:ro' \
  -v '/путь/к/результатам:/data/out' \
  --entrypoint python osseo-no-new-labels:20260926 \
  run_no_new_labels.py --input /data/in --output /data/out \
  --profile /profile/profile.json
```

Для существующего API перед запуском его процесса задайте абсолютные `DXAQC_ANATOMY_MODEL` (anatomy.json), `DXAQC_QUALITY_REVIEW_MODEL` (quality_review.joblib), `DXAQC_PROJECTION_MODEL` (projection.joblib) из каталога профиля. API отдаёт кандидаты анатомии и сравнения ROI через существующие оценки; запуск через CLI дополнительно проверяет полный профиль кода и весов. Загружайте только доверенные локальные joblib-артефакты.

Исследовательские результаты и манифесты сохранены в `data/specialists/runs/{anatomy-mask-stage1-20260926,anatomy-mask-stage2-20260926,hip-mask-stage1-20260926,dxa-defect-curriculum-20260926,femur-curriculum-20260926,quality-review-stage1-20260926}`. Они не коммитятся вместе с исходными медицинскими данными.

Инженерный путь выполнен и доступен для запуска. Все критерии ТЗ нельзя объявить доказанными: перенос анатомии на GE, отдельные ориентиры таза/бедра и клиническая точность оценки укладки остаются ограничениями текущего решения. Дальнейшая работа возможна на уже имеющихся данных; получение новых врачебных меток не выставляется обязательным следующим шагом.
