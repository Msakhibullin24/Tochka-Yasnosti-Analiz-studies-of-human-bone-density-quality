# Скачать данные для обучения

Проверено 17.09.2026. Команды выполняются из корня проекта. Нужен Python 3.10+ и интернет; GPU, аккаунт Hugging Face, токены и дополнительные Python-библиотеки для загрузки не нужны.

## Начать с двух небольших наборов

```bash
python3 backend/scripts/download_training_data.py
```

Команда скачивает только Ramathibodi и HipRay, суммарно **72,48 МБ**, в `data/external/`. Проверенные существующие файлы пропускаются. Источники, размеры и контрольные суммы зафиксированы в `docs/competition/download_sources.json`. Ошибка загрузки не превращается в готовый файл. Повторный запуск докачивает набор на уровне отдельных файлов; частично скачанный большой архив начинается заново. Одновременно запускать несколько загрузчиков в одну папку не нужно.

На машине с 5090 достаточно иметь эти два файла проекта: скрипт в `backend/scripts/` и каталог источников в `docs/competition/`, с сохранением структуры каталогов. Либо перенести уже скачанную папку `data/external/` и выполнить команду для проверки.

```bash
# Показать доступные варианты, размеры и лицензии без скачивания
python3 backend/scripts/download_training_data.py --list

# Только снимки и маски бедра/таза
python3 backend/scripts/download_training_data.py --dataset hipray

# Выбрать каталог на другом диске
python3 backend/scripts/download_training_data.py --output /path/to/datasets

# Необязательный большой архив детского таза: 1,87 ГБ
python3 backend/scripts/download_training_data.py --dataset mtddh
```

Архивы автоматически не распаковываются. `osteoporosis.zip` можно открыть обычным архиватором; `MTDDH.rar` требует архиватор с поддержкой RAR. Места для распаковки нужно больше указанного размера загрузки. На текущей машине Ramathibodi уже распакован в `data/external/ramathibodi/extracted/`.

## Что использовать и зачем

| Набор | Где окажется | Применение в нашем проекте |
|---|---|---|
| Ramathibodi | `data/external/ramathibodi/osteoporosis.zip` | DXA позвоночника/бедра, маски ROI; первый эксперимент с анатомической разметкой. После дедупликации 40 BMD и 20 VFA, 20 файлов масок. VFA — отдельная проекция |
| HipRay | `data/external/hipray/HipRay/` | 139 рентгенограмм + 139 масок, 256×256. Метки 0=фон, 1=бедренные кости, 2=тазовые кости. Учить сегментацию, а не конкурсное качество DXA |
| MTDDH | `data/external/mtddh/MTDDH.rar` | Необязательное обучение ориентиров детского таза. По статье 2 156 изображений с разным составом аннотаций; полный архив здесь пока не проверен |

Ramathibodi уже прошёл локальный аудит. Его метки качества нельзя напрямую переносить в наши бинарные классы: отличаются определения и пороги, встречаются нанесённые на изображение контуры. Для масок требуется проверить соответствие координат NRRD и DICOM. В HipRay грубые маски костей не дают отдельной разметки малого вертела или готовой оценки ротации.

Источники и лицензии:

- [Ramathibodi, карточка](https://data.mait.ai.in.th/dataset/bone-mineral-density-and-vertebral-fracture-asseessment-public-sharing), [прямая загрузка ZIP](https://data.mait.ai.in.th/dataset/26f345fb-8f2a-4175-8331-102cf790bd00/resource/7ce7cc71-95e6-4b30-a99e-58799527da49/download/osteoporosis.zip): Creative Commons Attribution в метаданных.
- [HipRay, исходный набор](https://data.mendeley.com/datasets/zm6bxzhmfz/1), [подготовленные файлы](https://huggingface.co/datasets/VictorButoi/flexray-data/tree/6219d411cc3f10572182f37668d87c531f0974f5/HipRay): CC BY 4.0. Скрипт получает только папку HipRay, а не весь репозиторий с другими наборами. README и LICENSE входят в загрузку.
- [MTDDH, метаданные Figshare](https://api.figshare.com/v2/articles/27999131), [прямой RAR](https://ndownloader.figshare.com/files/51075122): CC BY 4.0 по метаданным этой публикации данных. Размер и MD5 издателя зафиксированы; это проверка целостности архива, не аудит его разметки.

## Что пока не считать простой доступной загрузкой

- Arak: авторский Google Drive при проверке требует входа; нет проверенных файлов и лицензии данных.
- UK Biobank: заявка и одобренный доступ; не открытый ZIP для личной машины.
- BUU-LSPINE: на странице есть Google Drive sample и форма запроса полного набора. Описание 400 пар нельзя считать фактическим объёмом sample до проверки архива.

Не требуется скачивать эти источники, чтобы начать подготовку и первые эксперименты.

## Что ещё можно использовать

Готовые ImageNet-веса и DINOv2 — кандидаты для визуальных признаков; отдельный эксперимент с FleXray — для анатомии. Они не входят в команду загрузки датасетов. У FleXray-весов отдельная лицензия CC BY-NC 4.0, у обычного DINOv2 — Apache 2.0; доступность весов не доказывает качество на DXA.

Первый обучающий эксперимент по качеству всё равно должен опираться на конкурсные изображения с проверенной привязкой к Excel. Внешние маски помогают научиться находить кости, но не создают отсутствующие метки нарушений. План сравнения моделей: [решение по данным и модели](MODEL_AND_DATA_DECISION_RU.md).
