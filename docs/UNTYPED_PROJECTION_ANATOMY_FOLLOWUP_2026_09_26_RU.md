# Продолжение: типы нарушений, проекция и анатомия

Основной релиз 1.10.0 не изменён: все 27 хешей runtime совпадают с паспортом.
**19 ответов без типа пока сохраняются.** Новые результаты ниже не считаются
полным соответствием ТЗ. Отсутствие будущих врачебных разметок принято как
условие работы; новые разметки у пользователя не запрашивались.

## Типизация: проверена новая архитектура

Добавлен `MultilabelTypifier`: отдельный логистический классификатор каждого
официального критерия, вместо классификации редких комбинаций критериев.
Энкодер заморожен, C=.01 фиксирован. Для каждого исходного внешнего разделения
по исследованиям пороги выбираются на трёх внутренних разделениях **только
обучающих исследований**. Неполные и противоречивые исходные ответы исключены
из обучения; исходные метки не исправляются. Невыученный критерий не получает
положительного ответа из-за отсутствия обучающих примеров.

| Решение | Бинарный F1 | Чувствительность | Macro F1 типов | Пустых типов в OOF |
|---|---:|---:|---:|---:|
| Основной v5 | 0,57955 | 0,69863 | 0,48831 | 34 |
| Новые критерии, только вместо пустых ответов, с ограничением оси | 0,56604 | 0,61644 | 0,46168 | 0 |
| Новые критерии для всех снимков, с ограничением оси | 0,47826 | 0,60274 | 0,32929 | 0 |
| Без ограничения оси, только вместо пустых ответов | 0,57485 | 0,65753 | 0,46472 | 0 |

Ограничение оси: тип не выдаётся при отсутствующем измерении или наклоне не
более 5°. Варианты без ограничения сохранены только для диагностики: их
предсказание типа не доказывает выполнение физического правила ТЗ.

Замена пустых ответов новым решением повышает число пропущенных нарушений
с **22 до 28**. Поэтому отсутствие пустых строк не принято за улучшение.
На 19 релизных ответах новая модель предлагает 7 типов и 12 нормальных
ответов; это диагностика на снимках, использованных при обучении финальной
модели, а не независимая проверка. Эти ответы не перенесены в результаты.
Эталонные метки исходных снимков не копируются в инференс.

Итоговый эксперимент: `multilabel-typifier-v2-2026-09-26`. Первый технический
запуск помечен как отброшенный из-за изменения исходника во время выполнения;
в итоговых отчётах используются только результаты повторного запуска с
зафиксированным кодом.

## Проекция: использованы новые данные для обучения

К 939 исходным снимкам добавлены **512 синтетических AP-снимков всего
позвоночника**, выбранных с seed 17 только из опубликованного обучающего
раздела Spinal-AI2024. Источники имеют равную суммарную массу при обучении;
исходные пять разделений реальных пациентов сохранены. Модель, пороги и число
добавленных снимков не подбирались по новым результатам.

| Проверка | Исходный классификатор | С дополнением |
|---|---:|---:|
| AASCE, правильный принудительный AP | 27/98 | **41/98** |
| AASCE, уверенные ошибки | 32 | **12** |
| AASCE, неопределённые ответы | 64 | 76 |
| CDC NHANES II, правильный принудительный lateral | 13/13 | **12/13** |
| CDC, неопределённые ответы | 8 | 11 |
| CDC, уверенные ошибки | 0 | 0 |
| Два публичных GE-примера UKB | 2/2 | 2/2 |

На исходных реальных разделениях получены 800/800 правильных BUU-ответов,
40/40 Ramathibodi и 99/99 GE-ответов по слабой AP-метке протокола. Эти
результаты не подтверждают перенос на новое оборудование.

**AASCE не считается независимым клиническим тестом:** синтетические данные
могут быть производными его исходных снимков, а сам источник ранее изучался.
CDC — дополнительный источник боковых обычных рентгенограмм, не DXA;
13 снимков — фиксированный снимок состояния загрузки на момент эксперимента.
Исходные 16-битные TIFF преобразованы в uint8 по нативному min–max. Оценка
UKB основана на предыдущем визуальном чтении ИИ двух публичных примеров,
не на врачебном эталоне.

Прирост AASCE сопровождается ухудшением CDC и увеличением неопределённых
ответов. Новый классификатор сохранён как кандидат, в основной релиз не включён.

## Анатомия: проверены причины ошибок на GE

Добавлена проверка угла по центрам L1–L4 с раздельным масштабом X/Y. Функция
отказывает при неполных, нечисловых и нарушающих порядок уровнях; отсутствие
достоверных точек не превращается в нормальный угол.

На публичных DXA-пациентах медианная ошибка угла относительно оси именованных
ROI по предсказаниям вне обучения — **2,32°**. Это слабый ориентир по ROI,
не эталон анатомической оси.

На **68 из 99 GE-снимков** независимо предсказанные центры не сохраняют
порядок L1–L4. На остальных 31 снимке: 2 TP, 13 FP, 2 FN. Этот результат
имеет неполное покрытие; по всему исходному набору обнаружены только **2 из
10** положительных меток оси, ещё шесть положительных случаев не определены.
Метрики на 31 снимке не подменяют показатели на всех 99.

Добавлен совместный декодер тепловых карт с ограничением порядка уровней.
Он выбирает координаты каждого уровня по **его собственной карте** и не
перенумеровывает точки сортировкой. Это исправляет структурную возможность
перестановки уровней, но не подтверждает их анатомическую идентичность.
На всех 99 GE-снимках вычислены упорядоченные кандидаты: **6 TP, 56 FP,
4 FN**, F1 оси **0,16667**. Ограничение порядка увеличивает покрытие, но
не устраняет ошибку переноса; такой результат не внедрён в решение критерия.

Отдельный исследовательский CLI поддерживает этот декодер:

```bash
competition/.venv/bin/python competition/predict_spatial_anatomy.py \
  --model data/specialists/runs/spatial-dxa-adaptation-2026-09-26/spatial_dxa_head.pt \
  --input /path/to/spine.dcm --ordered
```

Выход содержит только кандидаты L1–L4, `verified=false`,
`clinical_validation=false`, `decoding=joint_order_prior`. L5, Th12,
подвздошные гребни и диски из ограничения порядка не выводятся.

Следующая работа по типам требует повышения чувствительности отдельных
критериев, а не заполнения пустых строк. Для анатомии выявлена ошибка переноса
на GE: ограничение порядка само по себе её не исправляет. Для проекции
требуется проверять одновременно AP и lateral на нескольких источниках,
поскольку улучшение одного источника уже сопровождалось ухудшением другого.
19 ответов без типа, Th12, гребни, диски и подтверждение пригодности
анатомической ROI остаются открытыми.

Полный набор проверок после изменений: **217 passed, 5 skipped**.
Проверены отсутствие пересечения исследований во внутренних разделениях,
отказ от всегда положительного критерия при отсутствии обучающего
подтверждения, ограничение оси, раздельный физический масштаб, отказ при
неправильном порядке точек и совместное декодирование без перенумерации.
Отдельный CLI с `--ordered` выполнен на реальном снимке. `git diff --check`
прошёл. Предупреждения относятся к исходным UID и намеренно отсутствующим
признакам в тестовых примерах; обязательных упавших проверок нет.

В загрузке CDC обнаружены три прерывания на медленном соединении. Загрузчик
сохраняет частичные файлы, проверяет полностью полученный `.part` перед новым
HTTP-запросом, допускает до 1 200 секунд на запрос и прерывает соединение,
если скорость длительно падает ниже 1 KiB/s. Состояние теперь сохраняется
по мере завершения каждого файла, без ожидания самого медленного предыдущего.
Продолжение запущено сервисом `osseo-dataset-nhanes-resume2-20260926`.
Три теста загрузчика прошли, включая новый тест завершённого частичного файла.
Полная выборка из 1 000 снимков ещё не заявляется скачанной.
