# Демонстрация технического выпуска 1.12.0

CPU-профиль — `tz-delivery-1.12.0`. Отдельный GPU-кандидат использует финальные
головы, обученные на всех 249 доступных метках, и более точную сеть ROI.
Точные image ID и области применимости: [CURRENT_RELEASE.json](CURRENT_RELEASE.json).
[Слайды](FINAL_PRESENTATION_RU.html) отделяют вложенную проверку качества от
обучения финальных весов и технической приёмки. Снимок прежней презентации
сохранён в [FINAL_PRESENTATION_1_11_7_RU.html](FINAL_PRESENTATION_1_11_7_RU.html).

## Локальный GPU-запуск

После загрузки переносимого образа:

```sh
./competition/local_run.sh serve 8091
```

Открыть `http://127.0.0.1:8091`. Скрипт использует настроенный Docker либо уже
работающий частный движок проекта, выбирает NVIDIA Toolkit или проверенное
подключение устройств и библиотек драйвера. Системная конфигурация не меняется.
Движок Docker должен работать. Для CPU остаётся `./competition/run.sh serve 8090`.

1. Загрузить `datasets/organizer/Для теста.zip`. Проверены все три DICOM,
   таблицы, изображения, SC/SR и побайтное сохранение ZIP. У пакета нет ответов;
   его демонстрация не измеряет F1 или медицинскую точность.
2. Открыть позвоночник: показать нумерацию L1–L4, физическую ось с порогом 5°,
   маски и ROI. Отличать найденные минимумы плотности от резервного контура;
   резервный контур не называется найденной межпозвоночной границей.
3. Открыть бедро: показать большой и малый вертел, ось шейки, отступы и
   предложенную ROI. Показать источник масштаба Y=1,05/X=0,6 мм. Наличие
   геометрии и совпадение с измерительной ROI не доказывают полную анатомическую
   правильность. Технический отказ локализации сохраняется явно.
4. Показать критерии и итоговые типы. Более точная отображаемая геометрия
   не подменяет фиксированные входы проверенных голов QC; исходные измерения
   доступны в расширенных диагностических данных.
5. При необходимости изменить геометрию, добавить комментарий и сохранить
   отдельное решение специалиста. История и экспертный отчёт не перезаписывают
   первоначальный машинный ответ.
6. Скачать CSV/XLSX, исходный ZIP и SC/SR. Показать отдельно валидность таблицы
   и `requirements_complete=false`. Показать `automatic_requirement_checks`:
   выполненные функции, неопределённые находки, необходимость проверки и
   `automatic_findings_resolved=false`. Выполнение вычисления не доказывает
   правильность анатомической оценки.
7. Отправить второй пакет после первого. В финальной сборке после 499 файлов
   успешно обработаны ещё три DICOM, и readiness остаётся положительной.

## Пакетная обработка

```sh
./competition/local_run.sh batch /absolute/input.zip /absolute/new-output
```

Веса при обработке не скачиваются. Для финального GPU-образа на RTX 4070
получены 499/499 Success, 146,02 с на CLI-пакет и 42,66 с как консервативная
граница на исследование с инициализацией моделей. HTTP-пакет — 147,57 с,
граница на исследование — 31,44 с; лимит ТЗ относится к исследованию.
Импорт Python и запуск Docker отдельно не включены в таймер инициализации.
Целевая H200 не измерялась.

Для CPU строгая проверка всех свидетельств:

```sh
./competition/run.sh batch /absolute/input.zip /absolute/new-output complete
```

Ожидается код **3** с сохранёнными результатами: полнота анатомических
свидетельств пока не достигнута. `submission` проверяет формат и отсутствие
Failure; `report` выполняет обработку без полного приёмочного требования.

Список входов сравнивать с `results_extended.csv`, строгие колонки —
с `submission.csv`. Для проверки списка, времени и ссылок SC/SR использовать
`competition/audit_delivery.py`. Агрегаты, хеши и протоколы:
[anatomy_upgrade_2026_10_15.json](competition/anatomy_upgrade_2026_10_15.json).

## Какие метрики показывать

F1 **0,6190**, ROC-AUC **0,8119** — поисковая вложенная проверка на 249
изображениях / 100 группах ранее изученной когорты. Это не оценка финальных
весов на собственном обучении и не результат закрытого теста. Средний F1
типов у этого варианта — 0,5363; наибольший 0,5971 получен другим вариантом.
Dice ROI **0,7623** относится к десяти опубликованным DXA и исключению
текущего DICOM-исследования из подбора шаблона, а не к полной сегментации кости.

ТЗ не задаёт численного порога F1 или формулы общего рейтинга. Глобальный
максимум не установлен. Закрытый тест и экспертная приёмка предусмотрены
у организатора; новые собственные врачебные метки не являются условием
запуска или материалом сдачи.

Новые проверки и их точные ограничения: [анатомия 1.12.0](AUTOMATIC_ANATOMY_1_12_0_RU.md).
