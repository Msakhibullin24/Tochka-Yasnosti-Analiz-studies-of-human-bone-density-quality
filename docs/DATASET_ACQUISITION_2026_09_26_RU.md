# Расширение внешних датасетов, 26 сентября 2026

Начата загрузка дополнительных публичных данных для проверки проекции,
локализации позвонков, масок тазовых костей и геометрии. Скачивание не означает
подтверждённое соответствие ТЗ: рентгенограммы, КТ и синтетические проекции
не дают эталонных меток качества исходных DXA организатора.

## Воспроизводимость и проверка

Основной каталог: `docs/competition/download_sources.json`.
Источники без опубликованных контрольных сумм:
`docs/competition/additional_dataset_acquisition.json`.
Для BUU, CGMH и примера UK Biobank SHA-256 вычислен локально после загрузки:
это контроль целостности нашей копии, а не предоставленная издателем подпись.
MedPelvis3D, LumASe и MTDDH проверяются по MD5 из официальных метаданных;
PPCNet зафиксирован на конкретной ревизии с Git/LFS контрольными суммами.

```bash
python backend/scripts/download_training_data.py --list
python backend/scripts/download_training_data.py --dataset medpelvis3d
python backend/scripts/download_training_data.py --dataset lumase
python backend/scripts/download_training_data.py --dataset mtddh
python backend/scripts/download_training_data.py --dataset ppcnet-2d
python competition/audit_downloaded_datasets.py
systemctl --user list-units 'osseo-dataset-*'
journalctl --user -u osseo-dataset-audit-20260926 --no-pager
```

Загрузчик сохраняет `.part`, запрашивает HTTP Range после обрыва и проверяет
ответ Content-Range. Если сервер игнорирует Range, файл начинается заново,
а не склеивается с полным ответом. Завершённые локальные файлы с другой
контрольной суммой не перезаписываются. ZIP проверяются на CRC, выход пути
за пределы каталога и символьные ссылки. Архив RAR проверяется по издательской
контрольной сумме; отдельная проверка распаковки RAR ещё требуется.

Скачивание и аудит продолжаются в пользовательских заданиях systemd с именами
`osseo-dataset-*-20260926`; они работают независимо от диалога, но не являются
постоянными заданиями после перезагрузки. Аудит ограничен 24 часами.
До распаковки крупных архивов нужно сверить суммарный распакованный размер
с доступным местом. Не следует одновременно распаковывать все КТ без этой проверки.

Проверка изменений загрузчика и аудита: восемь тестов прошли, включая возобновление,
игнорирование Range, повреждённый ZIP, небезопасный путь и символьную ссылку.

## Ограничения доступа и лицензий

* Полная когорта UK Biobank требует одобренного доступа. Открытый пример доступен,
  но явная лицензия для обучения и повторного распространения не установлена.
* Полная редакция BUU на 3 600 пациентов связана с формой запроса. Два публичных
  архива скачиваются отдельно. У BUU действуют условия университета; CC-лицензия
  не предполагается. Копия страницы с условиями сохранена в source-metadata.
* Mendeley `5jdfdgp762` и `zg4d3f9kyf` вернули HTTP 403 при обращении с этой машины.
  Первый источник частично производный от BUU, поэтому требует проверки утечки.
* У CGMH метаданные Kaggle указывают CC0, а описание ограничивает использование
  исследованиями и обучением. Это расхождение сохранено, набор не включается
  автоматически в распространяемый продукт.
* У PPCNet заявлена MIT; происхождение из VerSe/CTSpine1K и исходные ограничения
  следует сохранить отдельно от лицензии кода.

Новые данные не внесены в основной релиз и не изменили его 19 ответов без типа.
Следующая оценка должна разделять реальные DXA, обычные рентгенограммы, КТ и DRR,
сохранять разделение пациентов и исключать дубли до обучения и подсчёта метрик.
