# Контракт исходной ROI в DXA QC 1.10.0

ТЗ §2.4 описывает DICOM без разметки, а §2.2 требует проверять корректность
разметки. Разъяснения V2 не задают её контейнер и назначение. Ниже описан
реализованный локальный контракт; его нельзя считать согласованием организатора.

## Поддерживаемые структуры

- DICOM Overlay с Overlay Type `R`, отдельными однобитными данными,
  единственным кадром и корректным Overlay Origin. Embedded overlays не поддержаны.
- Замкнутый двухмерный `POLYLINE` в Graphic Annotation с единицами `PIXEL` и
  слоем `ROI` либо `ROI_*`. Нужна корректная ссылка на исходный SOP Instance UID.
- Сопроводительный GSPS с известными исходными изображениями в том же пакете.
  GSPS связывается с источником и не экспортируется как дополнительный анализируемый
  снимок. Неподдержанный или несвязанный объект получает обычную строку отказа.

Координаты возвращаются к центрам исходных пикселей с нулевой индексацией.
Overlay Origin исходно однобазовый; GSPS PIXEL описывает края пикселей, поэтому
применяется сдвиг −0,5. Отверстия и раздельные компоненты Overlay сохраняются;
обычная рамка или графика без явного назначения ROI не считается анатомической зоной.

## Назначение зоны

Назначение читается только из явного Overlay Label либо Graphic Layer.
Форма контура не используется для угадывания назначения.

| Явное обозначение | Назначение в отчёте |
|---|---|
| `ROI_FEMORAL_NECK` / `FEMORAL_NECK` | Шейка бедра |
| `ROI_TOTAL_HIP` / `TOTAL_HIP` | Общая область бедра |
| `ROI_SCAN_COVERAGE` / `SCAN_COVERAGE` | Область для проверки охвата |
| `ROI_L1`…`ROI_L4` / `L1`…`L4` | Именованная зона позвонка |
| `ROI` или другая метка | Назначение неизвестно |

Это локальные явные имена, а не обязательные значения стандарта DICOM или
утверждённый словарь организатора. При неизвестном назначении анатомический
вердикт остаётся неопределённым.

## Что проверяется

Для области охвата измеряются отступы 30 мм сверху/снизу и 20 мм с боковой
стороны. Эти ограничения не применяются к ROI шейки или отдельного позвонка.
Для явно названной ROI шейки показываются отношения к кандидатам шейки и
большого вертела: шейка должна принадлежать зоне, большой вертел исключаться.
Наличие точки внутри контура не подтверждает включение/исключение всей структуры;
результат остаётся запросом на анатомическую проверку.

Проверенная нумерация L1–L4, межпозвоночные границы и сегментация пока отсутствуют.
Отсутствующая исходная ROI записывается как `absent`; она не заменяется
искусственным полигоном и не считается доказанной ошибкой разметки.

Геометрия, которую специалист добавляет в редакторе, сохраняется отдельно от
исходной ROI и машинного ответа. Перенос пользовательского полигона — дополнительная
геометрическая функция, не автоматическое восстановление анатомической разметки.
