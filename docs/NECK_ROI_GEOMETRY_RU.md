# Геометрия явной ROI шейки бедра

Основание — §2.7 методических рекомендаций из исходной папки задания:
ROI шейки не захватывает большой вертел, включает мягкую ткань по обе стороны
и располагается перпендикулярно шейке. Седалищная кость может частично попадать
в ROI; любое её пересечение не объявляется автоматическим нарушением.
Числовой угловой допуск и минимальная ширина мягкой ткани в этом описании не заданы.

## Реализация

`competition/dxaqc/neck_roi_geometry.py` вызывается из общей `image_assessment`:
одиночный API и пакетный CLI/API используют одинаковую проверку. Результат
сохраняется в `source_roi_assessment.neck_geometry` расширенного CSV и
`assessment.source_roi.neck_geometry` JSON; отображается в анатомической панели.

Проверяются только ROI с явным назначением `femoral_neck`. При отсутствии
такой ROI статус — `not_applicable`. Для вычислений нужен известный физический
масштаб и маска бедренной кости. Маски читаются из точных растров RLE; поля
масок не заменяются выпуклыми оболочками.

Вычисляются:

- Число пикселей кости внутри ROI и число пикселей ROI.
- Кандидаты участков вне маски бедренной кости по обе стороны ROI и их
  протяжённость в мм. Эти пиксели могут принадлежать другим костям; они не
  объявляются подтверждённой мягкой тканью.
- Угол ROI к отдельно локализованной оси шейки и отклонение от 90°, если такая
  ось доступна. Обе оси переводятся в физические координаты с раздельными X/Y.
- Пересечение ROI с полными именованными масками большого вертела и седалищной
  кости, если они доступны. Одна точка не заменяет полный контур структуры.

## Существенные границы

Ось бедренной кости внутри самой ROI зависит от формы этой ROI. Её PCA сохраняется
лишь как описательное измерение `bone_within_roi_axis_angle_deg` и не подставляется
вместо анатомической оси шейки. При отсутствии отдельной оси угол
`roi_to_neck_axis_angle_deg` остаётся null. Для квадратной ROI без однозначной
главной оси ориентация также не устанавливается.

Текущие hip-веса содержат маски femur, hemipelvis и femoral_neck_roi; отдельных
масок большого вертела/седалищной кости и линии оси шейки у них нет. Эти
подпроверки явно остаются unavailable. Независимый локализатор и экспертные
контуры потребуются для их проверки. Никакое значение IoU само по себе не
подтверждает клиническую корректность ROI.

`clinical_verdict=undetermined` сохраняется. Новые измерения не меняют класс
качества на основании неподтверждённых кандидатов и не вводят числовой
угловой порог, отсутствующий в ТЗ. Правило охвата 30/30/20 мм остаётся отдельным
правилом для явно заданной `scan_coverage`, не для ROI шейки.

## Проверка

Регрессионные тесты охватывают известную перпендикулярную ось, анизотропный
масштаб, отсутствие независимой оси, симметричную ROI, отсутствие кости внутри
ROI, отсутствие участка с одной стороны и точное пересечение с полной маской.
Пакетный интеграционный тест использует реальный DICOM Overlay с меткой
ROI_FEMORAL_NECK, проверяет сохранение измерений в CSV и отсутствие ошибочной
подмены типа на охват сканирования. Это синтетические проверки программы,
не экспертная оценка реальных DXA.
