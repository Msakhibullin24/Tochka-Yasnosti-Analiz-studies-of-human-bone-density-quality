# Первая очередь независимой DXA-разметки

Для закрытия анатомических пунктов ТЗ подготовлены две небольшие офлайн-очереди из существующего слепого пакета v4:

| Очередь | Как выбрана | Объём | Назначение |
|---|---|---:|---|
| `audit` | 25 случайных групп исследований; класс и прогноз при выборе не использовались | 62 изображения | Зафиксированный до новой разметки эталон анатомии и проекции. Не использовать его метки для выбора архитектуры, порогов или дообучения. |
| `development` | Ошибки бинарного QC в остальных группах: 22 пропуска и 22 ложные тревоги | 44 изображения | Разбор причин и обучение кандидатов; выборка намеренно смещена к ошибкам. |

Обе очереди находятся в `data/tz-delivery-1.11.0/priority-anatomy-review-20260929-verified/`. Для специалиста открыть `audit/index.html` либо `development/index.html` локально; каждой очереди можно передать только её каталог. Страница не содержит прогнозов, классов качества или причин отбора. Файл `selection.json` в родительском каталоге нужен разработчику для воспроизведения выбора, специалисту его передавать не требуется. Изображения могут содержать исходные надписи внутри пикселей; пакеты предназначены для доверенного локального контура.

Разметка и выгрузка подтверждённого эталона выполняются по [инструкции v4](ANATOMY_REFERENCE_REVIEW_RU.md). Для оценщика нужен исходный `results_extended.csv` и исходные DICOM; шаблон очереди сохраняет SHA исходного отчёта и DICOM/пикселей. Разметку `audit` оценивать однократно после фиксации модели; `development` можно использовать в итерациях обучения. Обе части происходят из уже изученных исследований организатора и не становятся новым независимым тестом общего QC. Пациентская независимость групп по обезличенным метаданным не доказана.

Воспроизведение очередей на том же слепом пакете и зафиксированном OOF:

```sh
PYTHONPATH=competition competition/.venv/bin/python competition/prepare_priority_anatomy_review.py \
  --package data/tz-delivery-1.11.0/blind-anatomy-review-v4 \
  --oof competition/reports/quality_review_axis_guard_posthoc_2026_09_29.csv \
  --output /absolute/new-review-queues
```

Скрипт проверяет уникальность изображений, согласование групп с OOF и SHA исходных PNG. Очереди не пересекаются по группам исследований. Он не создаёт медицинских меток и не меняет рабочую модель 1.11.5. Для полноценного закрытия ТЗ дополнительно нужны реальные DXA с уже нанесёнными правильными и неправильными ROI, поскольку исходный набор организатора такой разметки не содержит.

Проверка готовых очередей: `audit` — 62 изображения из 25 групп,
`development` — 44 изображения из 37 других групп; все 112 файлов в двух
манифестах совпадают по SHA-256, пересечение групп равно нулю. В число
файлов входят PNG и служебные JSON/HTML/JS; медицинских меток в браузерных
пакетах нет.

## Доступ к новым данным и вычислениям

Разрешение на загрузку моделей и данных учтено. После удаления внешних
датасетов по запросу пользователя на локальном диске было 67,5 ГиБ свободно;
драйвер NVIDIA на этом ПК недоступен. Новые десятки гигабайт смежных
CT/рентгеновских наборов не дадут независимых меток качества DXA.
[UK Biobank](https://community.ukbiobank.ac.uk/hc/en-gb/articles/34219417027997-DXA-Regions-of-Interest-ROI)
предоставляет сырьевые DXA в рамках одобренного доступа, причём исходные
области анализа заданы в закрытом ПО;
[NHANES](https://wwwn.cdc.gov/Nchs/Data/Nhanes/Public/2017/DataFiles/DXXFEM_J.htm)
публикует коды причин невалидности бедра, но соответствующий открытый файл
содержит табличные измерения, а не привязанные к ним пиксели сканов.
[ISCD DXA Atlas](https://iscd.org/iscd-dxa-atlas/) имеет примеры ошибок,
но доступ к изображениям и их использование ограничены условиями для членов.
Эти источники полезны для последующего соглашения о доступе и протокола
разметки; автоматически скачивать их как готовый эталон нельзя.
