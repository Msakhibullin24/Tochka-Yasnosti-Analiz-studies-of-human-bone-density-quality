## Реализованные изменения

| Этап | Результат | Проверка / граница |
|---|---|---|
| Приёмка результатов | CLI принимает `--acceptance report/submission/complete`; отклонение возвращает 3, отчёты сохраняются. `run.sh batch` требует валидную таблицу без Failure | Регрессионные тесты для пустого типа и неполного покрытия; успешный запуск процесса не равен полной приёмке |
| Проекция до QC | Обученная проекция позвоночника проверяется до геометрии и классификации. Lateral/unknown дают явный отказ | Проверены снимки без ViewPosition; модель для бедра остаётся неполной, её эвристика не выдаётся за валидированный классификатор |
| Исходная ROI участвует в решении | Явная ROI_SCAN_COVERAGE с известным масштабом и нарушенными отступами добавляет официальный тип ошибки ROI | Обе области масштаба учитываются; правило не применяется к ROI шейки. Анатомическая правильность рамки шейки остаётся отдельной задачей |
| Независимость ROI у дубликатов | Кэш содержит только вывод по пикселям; отдельная ROI не меняет ответы другого изображения | Два одинаковых растра с разной ROI дают разные корректные результаты, инференс базовой модели выполняется один раз |
| Отображение проекции | Lateral отображается как кандидат боковой проекции в интерфейсе и текстовом экспорте | Тест React и тест формулировки экспорта |
| Полный комплект весов | Профиль, обе анатомические модели, модель проекции и вторичного пересмотра включены в `competition/models/workflow/` и Docker-образ | Проверены SHA-256 и вложенные веса; упаковка атомарна, предыдущее содержимое не перезаписывается |
| Права доступа в контейнере | Профиль/веса читаются непривилегированным пользователем; проверка загрузки включена в сборку после USER | Исправлена закрытая директория временной упаковки; тесты проверяют 0755/0644 |
| Согласование метрик | Генератор материалов требует evaluation именно поставляемого вторичного типизатора | Метрики прежнего baseline нельзя подставить как метрики профиля с пересмотром решений |

Вторичный типизатор выбран как часть явного профиля; он не подставляет случайный
тип в пустое поле. Он может подтвердить тип либо отменить тревогу. На ранее
просмотренном OOF F1 растёт с 0,580 до 0,601, но чувствительность падает с 0,699
до 0,630, ROC-AUC с 0,801 до 0,790 и macro-F1 типов с 0,488 до 0,479.
Это компромисс, который не следует скрывать за заполненностью таблицы.

## Воспроизводимые команды

```sh
make verify
./competition/run.sh build
./competition/run.sh batch /absolute/input.zip /absolute/new-output
```

Для проверки полного покрытия, используя поставляемый профиль:

```sh
DXAQC_WORKFLOW_PROFILE="$PWD/competition/models/workflow/profile.json" \
PYTHONPATH=competition competition/.venv/bin/python -m dxaqc.cli \
  --input /absolute/input.zip --output /absolute/new-output --acceptance complete
```

Код 3 означает отклонение приёмки и не удаляет результаты. Код 2 — ошибка входа
или конфликт выходного каталога. Программный режим `report` сохраняет прежний
контракт исследовательского запуска; его код 0 не свидетельствует о выполнении ТЗ.

Теперь инициализация головы явно задаётся seed0 независимо от вычисления
или загрузки признаков. Старый случайный поток зависел от создания ResNet;
поэтому новый эксперимент не является изолированной проверкой только
выбора поля обучения. Ранее просмотренные наборы не объявляются новой
независимой проверкой. Архивированы исходники использованного обучения.
Исправлен целочисленный тип индексов при отсутствии DXA-примеров.
Проверки кеша, совпадения обученных весов и оценки нумерации прошли;
совокупность профильных Python-тестов — 45.

## Полная видимость Th12: геометрия и обученный кандидат

Реализована геометрия полного проецируемого тела с допустимыми точками за
границей кадра: отдельно рассчитываются доли видимой площади и высоты.
Их равенство не предполагается. Учтены границы пиксельных ячеек, невидимые
тела, вырожденные и самопересекающиеся четырёхугольники.

Из 425 исходных AASCE-снимков подготовлены 2125 вариантов вырезки с пятью
степенями видимости Th12. Полный исходный четырёхугольник сохраняется даже
за кадром; целевые значения рассчитываются геометрически. Все варианты
одного исходного снимка остаются в одной группе. Это обычная рентгенография
с искусственными вырезками, а не новая экспертная DXA-разметка.

Обучен отдельный регрессионный кандидат: 272 исходных снимка для обучения,
68 для калибровки, 85 для проверки. Вход — только пиксели. Средняя абсолютная
ошибка доли высоты 0,247 против 0,300 у постоянного прогноза. Радиус
калиброванного по исходным группам диапазона 0,729: на 425 проверочных
вырезках все решения о половине тела неопределённы. Покрытие диапазоном
96% отдельных вырезок и 85,88% групп целиком; гарантия для DXA отсутствует.

Перенос на 99 исходных DXA после проверки идентичности файлов и пикселей:
99 неопределённых решений, точность не рассчитана из-за отсутствия
подтверждённых полных Th12-границ. Кандидат не включён в поставку; требование
половины тела Th12 остаётся открытым. Исходник проведённого обучения
архивирован с проверенной контрольной суммой. Последующая защита отклоняет
NaN и бесконечные прогнозы до ограничения диапазоном [0,1].

Прошли 10 новых проверок геометрии, формирования вырезок и протокола
неопределённости; совокупность профильных Python-тестов — 55.
Отчёты: `competition/th12_amodal_dataset_2026_09_27.json`,
`competition/th12_visibility_training_2026_09_27.json`,
`competition/th12_visibility_dxa_2026_09_27.json`.

## Продолжение 28 сентября: прямой классификатор половины Th12

На уже подготовленных 2125 вырезках обучен отдельный ExtraTrees-кандидат для

272/68/85 сохранены; калибровка берёт максимальную ошибку среди пяти видов
