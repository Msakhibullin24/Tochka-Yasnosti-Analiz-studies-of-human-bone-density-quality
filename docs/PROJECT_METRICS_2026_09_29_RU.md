## Техническое исполнение рабочей сборки 1.11.4

Офлайн-контейнер 1.11.4 обработал организатора **502/502**, внешние Hologic
BMD **60/60**; все **30/30 VFA** получили ожидаемый отказ
`UNSUPPORTED_PROJECTION`. Формат таблицы валиден для всех трёх запусков,
но VFA не проходит режим приёмки `submission` из-за Failure. У организатора
получено **146 положительных ответов** вместо 158 в 1.11.3.
При построчном сравнении 592 DICOM изменились только 13 типов оси с
измеренным углом ≤5°: у 12 строк класс изменился с 1 на 0, у одной
сохранился иной тип нарушения. На BMD и VFA медицинские решения не менялись.
Для всех 592 строк совпали статус обработки, область, UID, путь исследования,
score и код отказа. Ни одного положительного типа оси с углом ≤5° в новом
прогоне нет. Это программная проверка порогового правила, не подтверждение
точности измеренного угла. [Строгое сравнение и SHA-256](competition/workflow_1_11_4_axis_guard_2026_09_29.json).

Дополнительно зафиксирован повтор на исходных DICOM тем же закреплённым
профилем: **502/502** расширенных строк совпали по содержательным
полям с сохранённым выпуском 1.11.4 после разбора JSON-полей. Для первых шести изображений одного
исследования (позвоночник, оба бедра и повторные экспорты пикселей) одиночный
и пакетный вывод совпал **6/6** по медицинским и объясняющим полям;
исключались время обработки, служебный путь группировки, ссылка
`duplicate_of` и путь к файлу визуализации. Это проверка
воспроизводимости программного вывода, а не медицинской правильности.

## Анатомические критерии и отсутствующие метрики

Текущий `requirements.json` организатора содержит `complete=false`:
**Th12, подвздошные гребни и нумерация/ROI позвонков — 167/167
`undetermined`; проекция — 502/502; большой и малый вертел, шейка,
седалищная кость, охват и ротация бедра — 335/335** по каждому критерию.
Исходная ROI для 502 снимков отмечена `not_applicable`. Это счётчик
покрытия доказательств, а не частота клинических нарушений.

На 99 исходных GE DXA позвоночника экспериментальный классификатор
видимости половины Th12 выдал 99 `undetermined`; accuracy отсутствует.
Числа обучения Th12 на обычных рентгенограммах не переносятся на DXA.
Для переноса кандидата ориентиров шейки получено 122 ответа из 134
доступных масок бедра, но независимых DXA точек нет: ошибка в миллиметрах
и ошибка угла оси **не измерены**. Слепой пакет содержит 252 изображения;
подтверждённых специалистом случаев **0**.

Отдельная внутренняя проверка угла позвоночника при фиксированных 5°
нашла **1 из 10** размеченных нарушений оси. Это проверка текущей геометрии
по общей метке критерия, а не точность измерения углов отдельных позвонков.
Для клинической точности Th12, границ L1–L4, оси шейки, отступов ROI,
подтипов ротации и проекции бедра сейчас нет ни знаменателя с подтверждёнными
метками, ни честного F1/MAE/Dice.

## Архивные и планируемые показатели

Архивный `typed_v4` имел внутренний F1 0,577 и ROC-AUC 0,801 на 249
размеченных DXA; это другое решение и не метрика 1.11.3. Три независимые
shadow-модели версии 1.9.3 проверялись на общей подвыборке 46 DXA
(10 положительных): региональные сети F1 0,462 / ROC-AUC 0,639,
общий EfficientNet F1 0,372 / ROC-AUC 0,569, train-only гибрид
F1 0,432 / ROC-AUC 0,869. Текущий тогда `typed_v4` на тех же строках
дал F1 0,571 по **другому протоколу**. Эти shadow-сети не участвуют в
основном вердикте. [Парный аудит](INDEPENDENT_SPECIALISTS_PAIRED_AUDIT_2026_09_24_RU.md).

будущих измерений**, а не 31 достигнутый показатель текущей DXA QC
сборки. У проекта нет независимого клинического test, по которому можно
