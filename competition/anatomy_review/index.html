Независимая разметка DXA

Отметьте проекцию и видимость каждого ориентира. Для видимого ориентира укажите точку на исходном снимке. Координаты сохраняются в пикселях исходного изображения.

Специалист и источник разметки

Правки хранятся в этой странице до её закрытия. Регулярно скачивайте черновик; продолжить работу можно через «Загрузить черновик».

Изображение

Видимость

Выберите «Видим» и отметьте точку на снимке либо введите координаты.

Контуры областей

Отметьте вершины по порядку обхода контура. Для L1–L4 укажите область тела соответствующего позвонка; для шейки — анатомически корректную измерительную ROI. Измерительная ROI шейки должна быть выпуклой; контуры костей могут быть вогнутыми, но не должны пересекать себя. Для Th12 отмечайте только видимую часть: её контур не определяет размер полного тела позвонка.

Независимая ось шейки бедра

Отметьте два разных конца продольной оси шейки по анатомии. Не выводите эту ось из формы измерительной ROI.

Полное тело Th12

Оцените полную проекцию тела позвонка, включая часть за краем снимка. Если её границы нельзя обоснованно восстановить, выберите «Не удаётся оценить». Контур видимой части отмечается отдельно выше.

Четыре угла по порядку обхода, без самопересечения. Координаты за пределами снимка допустимы. Щелчок по снимку добавляет только видимую вершину; невидимые вводятся числами.

Что оценивает этот эталон

Точки, проекцию, именованные контуры Th12/L1–L4, костей бедра, ROI и независимую ось шейки, а также экспертную метку ротации. Подтверждение разметки не подтверждает точность модели.

Исходные пиксели могут содержать надписи аппарата. Пакет предназначен для локальной работы с разрешёнными данными.
