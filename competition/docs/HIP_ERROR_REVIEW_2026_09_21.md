# Разбор ошибок укладки бедра, 21.09.2026

Первый шаг перед изменением модели: парный разбор уже имеющихся отложенных
предсказаний по **одному** групповому разбиению (`repeat=0`). Источник —
`reports/scope_gate_1_9_pipeline_oof.csv`, 249 конкурсных изображений; вывод
`reports/hip_error_review_2026_09_21.json`. Это диагностический разбор внутренней
выборки, а не новая независимая проверка и не оценка клинической точности.

| Ошибка | Снимков |
|---|---:|
| Пропуск метки «укладка/ротация бедра» | 17 |
| Из них общий бинарный класс также отрицательный | 12 |
| Ложное срабатывание метки «укладка/ротация бедра» | 16 |
| Положительный бинарный класс без установленного типа, все области | 34 |

Изначально кандидат большого вертела отбрасывался на всех 33 ошибочных
снимках: маска бедра соединялась с тазом, который касался верхней границы
кадра. Проверка границы теперь ограничена латеральной зоной самого кандидата.
После исправления верх большого вертела предлагается на 11/17 пропусков и
8/16 ложных тревог; малый вертел — на 11/17 и 8/16, шейка — на 15/17 и
15/16, седалищная кость — на 17/17 и 16/16. Синтетический тест сохраняет
воздержание, когда именно латеральная часть кости уходит за границу.
Это рост доступности кандидата, **не доказательство анатомической точности**.
Ни один из этих ориентиров пока нельзя включать в жёсткое правило качества
без независимой проверки координат на целевых DXA.

Локальный пакет `data/audits/hip-error-review-reviewed-2026-09-21/` содержит
`cases.json`, `summary.json` и `review.html` с исходными снимками, наложениями
и измерениями. Он не хранится в Git из-за медицинских изображений. При
визуальном просмотре одного пропуска заметен выраженный малый вертел при
отрицательном решении, но среди ложных тревог также есть снимок с большим
значением этого же признака. Один порог по выступанию вертела поэтому не
обоснован.

Повторить разбор в образе `osseo-dxaqc:1.9.0`:

```sh
python audit_model_errors.py \
  --oof reports/scope_gate_1_9_pipeline_oof.csv \
  --labels labels/image_labels.csv \
  --dataset /path/to/Исследования \
  --output /path/to/new-review-folder --repeat 0
```

Следующий шаг — исследовать 33 ошибочных снимка и контрольные верные случаи
по группам: сбой сегментации контура, положение кости, физический масштаб,
качество самих меток. Затем сравнить новый геометрический признак с текущей
моделью на одинаковых групповых фолдах. Без экспертной разметки нельзя считать
улучшение координат анатомически подтверждённым.
