# Руководство пользователя

## Веб-интерфейс
1. Запустите сервис: `./run.sh serve` и откройте `http://127.0.0.1:8000/`.
2. Перетащите ZIP-архив с исследованиями (или несколько DICOM-файлов) в зону загрузки → «Запустить проверку».
3. Следите за прогрессом. По завершении доступны плитки сводки и кнопки **CSV / XLSX / ZIP с доп. сериями**.
4. Таблица: фильтры «все / только нарушения / только ошибки», поиск по пути и UID. Клик по строке открывает
   панель с визуализацией: ось позвоночника (зелёная — норма, красная — наклон > 5°), контуры артефактов,
   ориентиры бедра (GT — большой вертел, LT — малый вертел, IS — седалищная кость), серые линии — требуемые
   отступы 3 см сверху/снизу и 2 см сбоку; столбики вероятностей по каждому критерию; измерения в мм и градусах.

## Как читать результат
* `quality_class = 0` — исследование пригодно для интерпретации; `1` — требуется внимание специалиста.
* `quality_prob` — вероятность нарушения (0…1). Порог подобран по F1; для скрининга с приоритетом
  чувствительности порог можно снизить — AUC от этого не меняется.
* `violation_type` — метки организатора через «;». В колонке `violation_codes` — внутренние коды:

| Код | Что означает | Что делать |
|---|---|---|
| `spine_coverage` | не видны верхние края подвздошных костей и/или половина Th12 | повторить с корректной точкой старта |
| `spine_axis` | ось позвоночника отклонена > 5° (не сколиоз) | выровнять пациента по осевой линии стола |
| `spine_artifact` | металл, бельё, наложения | убрать предметы, исключить позвонок из анализа |
| `hip_position_rotation` | недо-/переротация (малый вертел), ось диафиза не вдоль сканирования | внутренняя ротация 15–25°, фиксатор стоп |
| `hip_roi_coverage` | меньше 3 см ткани над большим вертелом / под седалищной костью, 2 см сбоку | сместить точку старта |
| `hip_metal_implant` | эндопротез / металлоконструкция | исследовать контралатеральное бедро |
| `processing_failure` | файл не удалось обработать (см. `error_code`) | проверить файл |

## Командная строка
`./run.sh batch <папка|zip> <папка_результатов>` — без сети, один проход, в конце печатается сводка
(доля успешно обработанных, макс. время на исследование).

Результат ИИ является вспомогательным и требует подтверждения врачом-рентгенологом.
