# Проверка исследования

## Возможности 1.4.0

Карточки критериев показывают способ получения вывода, известные ограничения и доступные ориентиры. Кнопка показа ориентиров переключает на исходную машинную геометрию; результат классификатора и измеренный угол отображаются отдельно.

Для проверки ROI бедра добавьте полигон и выберите проверяемый боковой край изображения в его свойствах. Отступы измеряются от крайних координат выбранного полигона до крайних центров пикселей кадра: сверху/снизу 30 мм, с выбранной стороны 20 мм. Физический масштаб берётся из сохранённых метаданных. При масштабе по умолчанию результаты ориентировочные, перенос не предлагается.

При недостаточных отступах приложение может предложить перенос с сохранением формы и размера ROI. Предложение не применяется автоматически: сначала показаны исходные и новые координаты. После принятия проверьте соответствие анатомии; действие можно отменить. Если перенос невозможен, приложение не уменьшает ROI. Эта функция не является анатомическим локализатором и не пересчитывает BMD. Геометрическая оценка включается в сохранённую версию и её отчёт.

«Проверка формата ТЗ» скачивает протокол проверки таблицы. Комплектность входа, повторяемость и DICOM-серии не подтверждаются этой кнопкой; используйте CLI с манифестом, вторым результатом и опцией `--series` по `docs/FINAL_DEMO_RU.md`.

Многокадровые DICOM и явно заявленная в ViewPosition боковая проекция теперь получают отдельную ошибку. Экспортируйте индивидуальные изображения поддерживаемого типа. При отсутствии ViewPosition сервис не заявляет независимую проверку проекции.

## Возможности 1.3.0

- В «Изменить ориентиры и ROI» добавьте отметку или введите замечание к существующей геометрии. Отметку можно переместить на нужную область. Номер на снимке соответствует порядку объекта в списке.
- Выберите шаблон комментария и отредактируйте его под конкретный случай.
- Рабочая копия автоматически сохраняется в этом браузере. При следующем открытии снимка нажмите «Восстановить рабочую копию». Для передачи работы другому пользователю той же установки сохраните серверный черновик. Очистка данных браузера удалит локальные рабочие копии.
- В «Последующие действия» добавьте вопрос и выберите вид действия. Запрос «Второе мнение» появляется в одноимённом фильтре после сохранения версии. Для закрытия укажите результат и отметьте «Выполнено», затем сохраните новую версию. Сам выбор «Повторная обработка» не запускает алгоритм — это задача проверяющему.
- В истории решений доступны сравнение с текущей рабочей разметкой и скачивание отчёта конкретной версии. Отчёт содержит изображение внутри HTML и открывается без сервиса; его можно распечатать средствами браузера.
- У группы исследования доступна карточка всех его изображений. Она формируется из последних сохранённых версий; несохранённая рабочая копия в неё не входит. Сводка пакета открывается над списком исследований.
- Если другой пользователь сохранил новую версию, приложение покажет конфликт и предложит сравнение. Продолжение с вашими правками явно выбирает их как основу новой версии; изменения не объединяются автоматически.

Вводимое имя автора не проверяется учётной записью и не является электронной подписью. Автоматический обмен заданиями между отдельными установками пока отсутствует.

1. Открыть локальный Osseo AI. Проверить сообщение «Сервис готов».
2. Выбрать один ZIP либо несколько DICOM и нажать «Проверить». Архивы с несколькими уровнями вложенности поддерживаются в установленных лимитах.
3. Следить за прогрессом. «Остановить обработку» сохраняет уже готовые результаты, остальные файлы отмечает как отменённые.
4. В истории выбрать пакет. Фильтры разделяют нарушения и ошибки обработки.
5. Выбрать изображение. Preview показан без добавленных сервисом наложений, добавленные ориентиры можно отключить; масштабирование не меняет координаты разметки.
6. Сопоставить машинные типы нарушений с исходником, score, применёнными порогами и измерениями. Score не равен клинически подтверждённой вероятности.
7. В «Изменить ориентиры и ROI» исправить X/Y либо добавить полигон. Координаты 0–1 относятся к исходному preview. Отмена/повтор доступны отдельно.
8. Указать специалиста, итоговое качество, типы и комментарий. Сохранить черновик либо подтвердить решение. Для «Невозможно оценить» обязательна причина.
9. Скачать машинные результаты или отдельные экспертные результаты. JSON сохраняет все версии; экспертный CSV исключает последние черновики. HTML можно открыть и распечатать средствами браузера.

Правка не переобучает модель и не заменяет исходный результат ИИ. Перемещение линии пересчитывает её
физическую длину и угол в сохранённой экспертной версии; произвольный ROI не пересчитывает BMD.
Масштаб `device_default` является допущением, не измеренной калибровкой.

При конфликте версии открыть изображение заново и сверить последнюю редакцию. При сетевой ошибке
не считать правки сохранёнными, пока нет сообщения о новой версии. При переходе с несохранёнными
изменениями интерфейс запрашивает подтверждение.

Контроль ротации и охвата основан на обучении и эвристиках; точность ориентиров на реальной анатомии
ещё не подтверждена независимой разметкой. Вывод ИИ требует проверки специалистом. Исходные
DICOM хранить отдельно: сервис сохраняет нормализованные preview, отчёты и правки.
# Возможности 1.2.0: очередь и редактор

В выбранном пакете снимки объединяются по идентификатору исследования. Файлы без идентификатора показываются отдельно. Фильтр «Требуют проверки» включает непроверенные снимки и черновики; «Проверка завершена» — подтверждённые решения и решения «Невозможно оценить». Ошибки обработки учитываются отдельно. Кнопка «Следующий непроверенный снимок» обходит текущий отфильтрованный список. Если после сохранения снимок перестал соответствовать фильтру, он остаётся открыт, пока вы не перейдёте дальше.

В том же браузере после обновления страницы восстанавливаются последний пакет, снимок, фильтр и масштаб. В 1.3.0 текст и геометрия сохраняются в рабочей копии браузера; восстановление описано выше. Для записи серверной версии используйте «Сохранить черновик».

Для правки включите «Перемещать точки». Перетащите точку мышью или выделите её клавишей Tab и используйте стрелки. Шаг — один пиксель, с Shift — десять. Escape отменяет текущий жест. Числовой ввод координат остаётся в разделе «Изменить ориентиры и ROI». «Отменить изменение» отменяет весь жест перетаскивания.

Кнопка «Показать машинную разметку» открывает исходную геометрию без потери ваших изменений; «Показать мою разметку» возвращает редактор. Машинный результат остаётся прежним. Правки ROI не пересчитывают плотность кости и не означают устранения ошибки укладки. Сохраните черновик или подтвердите решение, чтобы записать новую версию.

## Неопределённый тип нарушения (1.7)

Если модель выявила нарушение, но ни один тип не подтверждён своим критерием, интерфейс показывает «Тип не установлен». Это требует проверки, а не означает отсутствие нарушения. Для подтверждения решения выберите обнаруженный тип; если снимок нельзя оценить, выберите «Невозможно оценить» и укажите причину. Незавершённое решение можно сохранить как черновик.

Отрицательный модельный класс сам по себе не подтверждает полноту анатомических проверок. Их ограничения включаются также в HTML, DICOM SR и дополнительное изображение SC. Исторические задания сохраняют исходную версию решения; новую версию можно получить повторной загрузкой DICOM.


## Таблица для сдачи V2 (1.8)

В новых пакетах доступны «CSV для сдачи», «XLSX для сдачи» и «Проверка таблицы для сдачи».
Проверка отклоняет, в частности, положительный результат без установленного типа.
Исправления специалиста сохраняются в отдельном CSV специалиста и не переписывают
исходную таблицу модели. Успех проверки формата не подтверждает точность анализа.

Для конкурсного аппарата источник масштаба подписан «Разъяснения организатора V2»:
X=0,6 мм, Y=1,05 мм. Старые пакеты сохраняют прежний масштаб и результаты;
для нового анализа их нужно загрузить заново. Новые конкурсные экспорты не
предлагаются для исторических пакетов, в которых они не были созданы.


## Физическое отображение и повторный анализ (1.9)

Предпросмотр, разметка и отчёты показываются в физических пропорциях X/Y.
Яркость preview нормализована; это не исходные значения DICOM и не измерение BMD.
Координаты экспертных точек по-прежнему сохраняются относительно исходной сетки.

Для новых заданий сохраняется архив исходных файлов, включая сопроводительные DICOM.
«Исходные DICOM» скачивает этот архив. «Повторить анализ новой версией» проверяет
контрольную сумму и создаёт новый пакет текущей моделью, сохраняя старые результаты
и экспертные версии. Старые задания без сохранённых исходников требуют повторной загрузки.

«Пакет экспертной проверки» содержит снимок истории reviews.json, HTML последних
подтверждённых/неоценимых версий, manifest с ревизиями, состояниями и SHA256.
Последний черновик не выдаётся за подтверждённый отчёт. Машинные DICOM SC/SR
не переименовываются в экспертные; их нужно получать через отдельную ссылку.

Низкая уверенность определения области теперь возвращает UNCERTAIN_REGION:
автоматический вердикт качества не формируется. Это ограниченный отказ по
уверенности роутера, а не доказанное распознавание всех посторонних изображений.
